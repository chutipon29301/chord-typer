    State machine transitions per D-06:
    - .idle + keyDown -> .collecting (open timing window per D-01, D-08)
    - .collecting + keyDown inside window -> add to heldKeys Set of UInt16 + append to bufferedEvents array (D-07, D-09, D-10)
    - .collecting + keyDown outside window (D-02) -> evaluate previous chord immediately, start new collecting cycle
    - .collecting + keyDown with modifier flags (D-03, D-04) -> abort: flush all bufferedEvents via eventPoster, reset to .idle
    - .collecting + keyUp -> remove from heldKeys, append to bufferedEvents. If heldKeys.isEmpty -> .evaluating
    - .evaluating -> check heldKeys count >= 3 (CHRD-02). If < 3, replay all buffered events. If >= 3, build sortedChordKey from static keycodeToChar table, call chordLookup. Match -> return .chord(key:buffered:). No match -> replay via eventPoster with isReplaying guard (D-11), return .suppress.

    sortedChordKey function: compactMap keycodes through table, sorted(), map String.init, joined().

    Timing window: DispatchWorkItem scheduled on same serial queue via queue.asyncAfter with deadline .now() + timingWindowMs / 1000.0. Cancel in every transition that exits .collecting. Work item calls evaluate with [weak self] guard.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CGEventTap -> ChordEngine | Raw keyboard events from driver level enter chord processing |
| ChordEngine -> CGEventPost | Replay events posted back to the system during mismatch |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | ChordEngine replay | mitigate | isReplaying guard (OSAllocatedUnfairLock) prevents re-entry; replay posts exact original CGEvent objects — no modification |
| T-04-02 | Denial of Service | Timing window | mitigate | Window capped at 200ms max (CHRD-01 range); DispatchWorkItem cancelled on every state exit; stale timer cannot accumulate |
| T-04-03 | Information Disclosure | Buffered events | accept | Events are raw keycodes held in memory briefly (~50ms); no persistence, no logging of key content; acceptable for local-only app |
| T-04-04 | Tampering | Modifier bypass | mitigate | D-03: any modifier flag aborts chord and flushes buffer — system shortcuts (Cmd+C etc.) never intercepted |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this phase — Apple frameworks only |
</threat_model>
