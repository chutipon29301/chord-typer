# Phase 2 — UI Design Contract

> Visual and interaction contract for native macOS SwiftUI menubar phases.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> NOTE: This is a native macOS app. There is no web framework, no CSS, no shadcn, no HTML.
> All design specifications reference SwiftUI APIs, SF Symbols, and macOS system appearance.
> "Spacing" and "typography" sections are expressed as SwiftUI system values, not pixel literals.

## Menubar Icon Contract

| State | SF Symbol Name | SwiftUI API | Notes |
|-------|---------------|-------------|-------|
| Active (chord detection on) | `keyboard.fill` | `systemImage: "keyboard.fill"` | Default on first launch |
| Paused (chord detection off) | `keyboard.badge.ellipsis` | `systemImage: "keyboard.badge.ellipsis"` | Visually distinct; stays in keyboard metaphor |

Icon switches dynamically via `@AppStorage("chordTyperEnabled")` binding on `MenuBarExtra`.
No tint applied — icon renders in standard menubar monochrome using system-provided rendering.

Source: CONTEXT.md D-06, D-07, D-08

## Menu Structure Contract

Menu style: `.menuBarExtraStyle(.menu)` — standard NSMenu dropdown, no custom popover window.

```
[keyboard.fill / keyboard.badge.ellipsis]  ← icon in menu bar

  ✓ Enable ChordTyper          ← Toggle; checkmark when active; D-05
  ─────────────────────────────
    Dictionaries  >            ← Submenu; D-03
      ✓ English                ← Toggle; checkmark when englishEnabled=true
        Thai                   ← Toggle; checkmark when thaiEnabled=true
  ─────────────────────────────
    Settings...                ← Placeholder; logs via os_log; D-14
    Open Dictionary Folder     ← Opens Resources/dictionaries/ via NSWorkspace; D-15
  ─────────────────────────────
    Quit ChordTyper            ← NSApplication.shared.terminate(nil); D-16
```

Source: CONTEXT.md D-03, D-04

## Menu Item Labels (Copywriting Contract)

All labels are exact strings. No abbreviations, no ellipsis except for Settings.

| Menu Item | Exact Label | Notes |
|-----------|-------------|-------|
| Primary toggle | `Enable ChordTyper` | Verb + product name; checkmark state conveys on/off |
| Dictionaries submenu | `Dictionaries` | Noun; no arrow needed (SwiftUI adds disclosure indicator automatically) |
| English dictionary toggle | `English` | Single word; checkmark when enabled |
| Thai dictionary toggle | `Thai` | Single word; checkmark when enabled |
| Settings stub | `Settings...` | Trailing ellipsis signals opens a window (standard macOS convention) |
| Open folder | `Open Dictionary Folder` | Descriptive action verb; no ellipsis (opens Finder inline) |
| Quit | `Quit ChordTyper` | Includes product name per macOS convention |

No empty states apply to this phase — the menu is always fully populated.
No error copy required in this phase — failures (e.g. NSWorkspace open failure) are silent at this phase (logged via os_log only).

## Interaction Contract

| Action | Trigger | Result |
|--------|---------|--------|
| Toggle ChordTyper on/off | Click "Enable ChordTyper" menu item | Flips `chordTyperEnabled`; icon changes immediately |
| Toggle English dictionary | Click "English" in Dictionaries submenu | Flips `englishEnabled`; checkmark updates immediately |
| Toggle Thai dictionary | Click "Thai" in Dictionaries submenu | Flips `thaiEnabled`; checkmark updates immediately |
| Open Settings | Click "Settings..." | Logs `os_log` message "Settings tapped — not implemented yet"; menu closes |
| Open Dictionary Folder | Click "Open Dictionary Folder" | Calls `NSWorkspace.shared.open(URL)` on the app bundle's `Resources/dictionaries/` path |
| Quit | Click "Quit ChordTyper" | Calls `NSApplication.shared.terminate(nil)` |

## Spacing / Layout

Not applicable. This phase uses only native NSMenu items. SwiftUI `MenuBarExtra(.menu)` delegates all layout (item height, padding, divider spacing) to the system NSMenu renderer. Do not inject custom padding or frame modifiers on menu items — this breaks native appearance.

---

## Typography

Not applicable. All text rendered by system NSMenu at system-standard sizes. No custom fonts, weights, or sizes. SwiftUI `Text` inside `.menu` style MenuBarExtra renders at NSMenu's native item size (system-controlled, approximately 13pt SF Pro Regular).

---

## Color

Not applicable. All color is system-semantic and appearance-adaptive. No hardcoded hex values. The menubar icon and all menu item text follow the system menu appearance automatically.

## Architecture Notes for Executor

- Single file scope: modify `Sources/ChordTyper/ChordTyperApp.swift` only
- Keep `@main` on `ChordTyperApp` — no AppDelegate this phase (deferred to Phase 3)
- `SWIFT_STRICT_CONCURRENCY=complete` is active — all code must be concurrency-safe
- `os.log` required for Settings stub log line; import `os` framework
- `NSWorkspace.shared.open(_:)` is the correct API for "Open Dictionary Folder"
- Icon binding: pass the SF Symbol name as a computed property based on `@AppStorage` value, or use two separate `MenuBarExtra` scene declarations conditionally (computed `systemImage` string is simpler)
