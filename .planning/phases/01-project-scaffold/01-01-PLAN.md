    - MenuBarExtra content: Text("ChordTyper is running") with .padding(), Divider(), Button("Quit") calling NSApplication.shared.terminate(nil)
    - .menuBarExtraStyle(.menu)
    - No main.swift (D-03), no @NSApplicationDelegateAdaptor (D-02)
    - No force unwraps, no print() -- use os.log if logging needed (but none needed here)

    Create `Tests/ChordTyperTests/ChordTyperSmokeTests.swift` per D-04:
    - Import XCTest
    - final class ChordTyperSmokeTests: XCTestCase
    - Single test method: func testSmoke_testPipelineExecutes() with XCTAssert(true, "Test pipeline is functional")
    - Use the simple assertion per RESEARCH recommendation (Bundle.main in test runner is the test bundle, not app bundle)
    - D-05: No pre-created stubs for future phases

    Create `Makefile` per SCAF-02 with targets: generate, build, run, test, dmg, clean.
    - SCHEME = ChordTyper
    - BUILD_DIR = .build
    - APP_PATH = $(BUILD_DIR)/Build/Products/Release/$(SCHEME).app (correct derived data path per RESEARCH Pitfall 3)
    - generate: xcodegen generate
    - build: depends on generate, runs xcodebuild -scheme $(SCHEME) -configuration Release -derivedDataPath $(BUILD_DIR) build
    - run: depends on build, runs open "$(APP_PATH)"
    - test: depends on generate, runs xcodebuild -scheme ChordTyperTests -configuration Debug -derivedDataPath $(BUILD_DIR) test (RESEARCH says verify scheme name with xcodebuild -list after generate; if scheme is named differently, adjust)
    - dmg: depends on build, runs codesign then hdiutil create
    - clean: rm -rf $(BUILD_DIR) *.xcodeproj
    - All targets declared .PHONY
