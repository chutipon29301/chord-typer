<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User -> TCC | User must grant Accessibility permission via macOS System Settings; app cannot bypass TCC |
| CGEventTap callback -> EventTapManager | C callback runs on unspecified thread; must bridge safely to Swift class state via Unmanaged pointer and serial queue |
| App binary -> TCC database | Ad-hoc re-signing invalidates TCC grants; tccutil reset mitigates during development |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | EventTapManager.createTap | mitigate | CGPreflightListenEventAccess() gate before CGEvent.tapCreate; NSAlert informs user; app runs in paused state without permission per D-08 |
| T-03-02 | Information Disclosure | eventTapCallback | accept | Phase 3 is pass-through only; no keystroke data is logged or persisted; callback only invokes eventHandler closure which returns event unchanged. Phase 10 adds secure input detection (SECR-01/02) |
| T-03-03 | Tampering | eventTapCallback Unmanaged pointer | mitigate | passRetained/release lifecycle managed exclusively in createTap/destroyTap; selfRetained stored as instance property; release only after tap disabled and RunLoopSource removed |
| T-03-04 | Denial of Service | tapDisabledByTimeout | mitigate | Immediate re-enable via CGEvent.tapEnable inside callback per D-09; sleep/wake recovery via NSWorkspace.didWakeNotification per D-10 |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No external packages installed in this phase; Apple system frameworks only |
</threat_model>
